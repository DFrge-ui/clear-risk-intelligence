# CLEAR — проект для портфолио Дмитрия Катаева

Это работающий учебный сервис на **Python / Flask / SQLite**: он проверяет CSV с синтетическими инцидентами, очищает допустимые значения, объясняет риск-флаги и готовит отчёт.

В разделе **О проекте** сохранена информация об учебном характере работы, синтетических данных и помощи AI. Проект не выдаёт себя за банковскую систему или коммерческий опыт. Сведения об образовании и трудоустройстве не добавлялись.

В верхней панели можно выбрать **English / Deutsch / Русский**. Переводятся интерфейс и управленческий отчёт; выбранные данные, фильтры и раздел сохраняются. Названия компаний остаются английскими. Это заглушки: вымышленные инциденты не описывают реальную деятельность этих компаний.

## Как открыть

1. Распакуй архив целиком в обычную папку.
2. Дважды нажми **run_windows.bat**.
3. При первом запуске установятся необходимые библиотеки. Затем откроется браузер: **http://127.0.0.1:5000**.
4. Не закрывай окно запуска, пока пользуешься сайтом. Чтобы остановить — Ctrl+C.

Требуется Python 3.11 или новее. Если его нет, установи с [python.org](https://www.python.org/downloads/windows/) с галочкой **Add Python to PATH**. Интернет нужен только для первой установки зависимостей. Сам сайт работает локально; данные не отправляются внешнему AI.

Если порт занят, открой терминал в папке проекта и выполни:

```powershell
.\run_windows.bat --port 5055
```

Если виртуальное окружение было создано в другой папке и перестало запускаться, закрой приложение, удали только папку `.venv` внутри проекта и снова запусти файл запуска.

## Что показать работодателю

1. **Overview.** Обзор 168 принятых синтетических инцидентов: суммы, активные случаи, динамика, очередь проверки и текст отчёта.
2. **Incident explorer.** Поиск, фильтры, страницы таблицы. Нажми на ID, чтобы увидеть причины флагов и строку источника.
3. **Data pipeline.** В исходном CSV намеренно есть четыре дубликата и три ошибочные записи. Здесь видно, что именно исправлено или исключено.
4. **Upload CSV.** Сначала файл проверяется. Только после просмотра результата кнопка Apply accepted records заменяет активный набор.
5. **Export.** CSV с обработанными строками, JSON для автоматизации и управленческий отчёт. Кнопка Print / save as PDF открывает стандартное окно печати браузера, где можно сохранить PDF.
6. **Behind the project.** Назначение проекта, архитектура, ограничения и все пять правил.

Демо рассчитывается на **24 сентября 2026 года**, чтобы результаты не менялись каждый день. Для другого синтетического файла дату анализа можно выбрать при загрузке. Для возврата к примеру используй **Restore sample**. На телефоне кнопка **Restore sample data** находится в разделе Data pipeline.

## Почему здесь нет «магического AI»

AI помогал при создании проекта. Сам анализ состоит из проверяемых правил, а management summary собирается из реальных итогов по шаблону. Это позволяет объяснить любую цифру и повторить расчёт. Проект не заявляет машинное обучение или подключённый LLM там, где их нет.

Нельзя обещать, что сайт гарантирует трудоустройство. Он даёт конкретный предмет для разговора: как ты разобрался в обработке данных, где помог AI, что ты проверил самостоятельно и чему собираешься научиться дальше.

## Где лежат данные

`data/demo_incidents.csv` — только выдуманные данные. `instance/` создаётся при запуске и содержит локальную базу и ключ сессии; не включай её в публичный репозиторий. Не загружай персональные или реальные банковские данные.

Локальная ссылка работает только на компьютере, где запущен сервис. Для отправки рекрутеру нужна отдельная публикация на хостинге с Python или репозиторий с инструкцией. В этом проекте публичный адрес не создавался.

## Названия компаний в демо

В качестве заглушек используются названия **Electroshield Samara**, **Samara BKK**, **Zhigulevskoye Pivo**. Все события, суммы и связи в таблице вымышлены и не описывают реальную деятельность компаний. Названия хранятся в поле `business_unit`, которое интерфейс показывает как Company / unit.

Переключатель English / Deutsch / Русский находится в верхней панели. Выбор сохраняется в браузере; текущий раздел, фильтры и набор данных сохраняются. Названия компаний показаны на английском, а информация об учебном характере данных вынесена в раздел «О проекте» и отчёты.
